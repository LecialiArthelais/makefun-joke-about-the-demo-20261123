# Joke candidates — scored against the judge's 5 criteria (in order)

Judge: z-ai/glm-5.3-flash, pairwise. Criteria, most important first:
1. On-subject joke about AI coding agents / something that crashed
2. Surprise punchline that makes sense instantly
3. Truth a developer recognises from their own demo
4. Economy — one line, every word earning its place
5. Freshness — new angle, not stock

Scores 1–5 per criterion. Length = Unicode code points (limit 280).
